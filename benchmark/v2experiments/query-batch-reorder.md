# PCA 批内排序对照

2026-11-24，本机 Core i7-12700KF、WSL 2、Release、AVX-VNNI，查询线程绑定在 vCPU 0–15。测试基于 `0fdc278` 加默认开启排序的改动。每个数据集和缓存档位复用同一个固定图和索引，热身后交替测试默认排序与按输入顺序执行，各 12 轮。计时包含查询投影、编码、排序、搜索和结果写回。

GIST1M 用 PCA128、`L=400`、`beam=6`、`refine_max=400`。SIFT1M 用 PCA64、`L=128`、`beam=8`、`refine_max=120`。两者均用 UINT4 查图、UINT4 粗排和 FP32 Top40。

小批每次提交 15 条查询，末批提交余量，搜索由一个线程完成。大批每次提交完整查询集，GIST1M 为 1,000 条，SIFT1M 为 10,000 条。QPS/thread 为中位整批 QPS 除以查询线程数。配对变化取每轮开启与关闭排序的吞吐比值的中位数。
