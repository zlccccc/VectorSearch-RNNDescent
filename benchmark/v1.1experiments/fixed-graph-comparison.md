# v1.0 与 v1.1 同图对照

2026-11-24，本机 Core i7-12700KF、WSL 2、Release、AVX-VNNI、16 查询线程，线程固定在 vCPU 0–15。`v1.0` 对应 `1413447`。`v1.1` 对应 `ba23258`，测量使用与它的求解器源码一致的 `e78da58`。

每个数据集复用同一张固定图，沿用 v1.0 的查询配置，每档轮换运行 36 轮。查图均用 UINT4。SIFT100K 用 FP32 直排，GIST100K 用 8 位粗排加 FP32 Top40，百万级用 UINT4 粗排加 FP32 Top40。[固定配置](../v1.0experiments/cross-platform.md#数据集参数)

QPS/thread 为各版的中位数。配对变化取各轮 v1.1 与 v1.0 的吞吐比值的中位数。峰值 RSS 包含底库加载、PCA、图装配和查询。
