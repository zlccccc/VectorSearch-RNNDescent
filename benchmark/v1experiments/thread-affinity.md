# 查询线程绑核

GIST100K，16 查询线程，使用 bitmap，36 轮交替。固定在 0–15 时先用偶数 vCPU，再用奇数 vCPU。[测试口径](README.md)

| 调度方式 | 全缓存 QPS/thread | 0 缓存 QPS/thread |
|---|---:|---:|
| 固定到 vCPU 0–15 | 3,130.6 | 3,914.4 |
| 在 vCPU 0–15 内自由调度 | 3,148.4 | 3,913.9 |
| 在全部 20 个 vCPU 内自由调度 | 3,111.9 | 3,913.0 |

同样使用 vCPU 0–15 时，绑核在全缓存和 0 缓存下的配对收益分别是 **0.0%** 和 **+0.1%**。三种调度都测得 **99.150%** Recall@10。

## 复测

绑核对照用 `taskset -c 0-15` 限制 CPU 范围。固定线程时设 `OMP_PROC_BIND=close` 和 `OMP_PLACES='{0},{2},{4},{6},{8},{10},{12},{14},{1},{3},{5},{7},{9},{11},{13},{15}'`。自由调度时设 `OMP_PROC_BIND=false`，清除 `OMP_PLACES`。
