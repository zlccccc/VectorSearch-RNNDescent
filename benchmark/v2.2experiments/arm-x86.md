# ARM NEON 与本机 x86

测试提交为 `c6521c9`。ARM 云机为海思 16 vCPU，报告 8 核、每核 2 线程、32 MiB L3，使用 Ubuntu 22.04、Linux 5.15、GCC 11.4 和 NEON Dot Product。本机为 Core i7-12700KF、WSL 2、GCC 13.3，实测 AVX2 INT8、AVX2 UINT8 和 AVX-VNNI。ARM Release 构建通过 102 项 CTest。本机 AVX-512 目标通过编译，CPU 缺少运行该目标所需的指令。

## 整批查询

两台机器复用同一份底库、查询、真值和图快照。同一编码档使用相同的 PCA 维度及查询参数。查询线程绑核，OpenBLAS 上限与查询线程数一致，OpenMP 使用被动等待、零自旋，默认启用 PCA 批内排序。各线程档正反交替跑 4 轮，取中位 QPS，QPS/thread 按线程数折算。SIFT 每轮 10,000 条查询，GIST 每轮 1,000 条。
