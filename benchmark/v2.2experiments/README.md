# v2.2 查询线程池优化

v2.2 优化查询线程的生命周期、任务派发和完成同步。单条查询按入口分片派发，小批按查询派发，两条路径默认共用每个索引的常驻线程池。调用线程处理第一份任务，其他工作线程按需唤醒，空闲时休眠。[查询调度配置](../../docs/configuration.md#查询调度)

Linux 使用 futex，Windows 等平台使用 C++17 条件变量。CMake 选择等待后端，任务执行和结果收尾共用一套代码。[线程池实现](../../solution/rnndescent/search/QueryWorkers.cpp)

GIST1M 和 SIFT1M 的最终版同图复测覆盖连续单条、固定小批、混合请求和整批。常驻线程池缩短了单条并行请求的延迟，并提高小批和混合请求的吞吐。整批动态领块另做了实验对照，两种派发方式的吞吐基本持平。[端到端复测](query-workers.md#v22-端到端复测) · [实验与跨平台验证](query-workers.md)
