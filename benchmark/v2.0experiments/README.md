# v2.0 Experiments

比较基准为 [v1.1](../v1.1experiments/README.md)。从 `00d9cbc` 开始记录批量调度和查询并行的实验。

v2.0 的目标是让查询支持串行、单查询内多线程，以及批量查询之间的多线程分工。单条用 `SearchConfig::single_query_threads` 配置，批量用 `SearchConfig::num_threads` 配置。用同图、同查询和 Recall@10 ≥ 99% 的结果对照单条延迟、QPS 和 QPS/thread。[查询接口](../../docs/api.md)

## 封板性能对照

基线为 `v1.1` tag（`ba23258`）。2026-11-25 在本机 Core i7-12700KF、WSL 2、AVX-VNNI Release 下测量。每个数据集复用归档固定图、查询和真值，按相同搜索预算提交查询。每档交替测 8 轮，同轮使用相同查询顺序，末批按实际余量提交。

测试使用 vCPU 0–15，工作线程按 `{0},{2},{4},{6},{8},{10},{12},{14},{1},{3},{5},{7},{9},{11},{13},{15}` 分散绑核。 `OMP_PROC_BIND=close`，统一使用 `OMP_WAIT_POLICY=ACTIVE`、`GOMP_SPINCOUNT=16000`，OpenBLAS 上限随查询线程预算设置。

查询计时包含投影、编码、排序、图搜索、重排和结果写回。图装配与 PCA 训练在查询计时外完成。表中为中位 QPS / QPS/thread，分母为配置的查询线程数。括号为相对同轮 `v1.1` 输入顺序的 QPS 比值中位变化。

### 数据集与搜索参数

四个数据集均用 UINT4 查图。GIST 每轮提交完整的 1,000 条查询，SIFT 每轮提交完整的 10,000 条查询。建图配置沿用归档图快照。 [固定图与建图参数](../v1.0experiments/cross-platform.md#数据集参数)

## 专项实验

- 百万级 PCA 批内排序，全缓存和零缓存对照。[PCA 批内排序](query-batch-reorder.md)
- 整批 SGEMM 与 SIMD GEMV 及高维小批的并行投影对照。 [查询 PCA 投影](pca-projection.md)
- GIST1M 和 SIFT1M 的查询分流、线程预算和批大小对照。 [调度复测](batch-thread-dispatch.md#当前工作区复测)
- OpenMP 自旋对连续吞吐、尾延迟和 CPU 时间的影响。 [单查询并行的等待开销](single-query-wait.md)

### 当前版单查询参数

调度复测中的 6、8 线程为实际查图线程数。全局重排候选数沿用上面的批量配置，`--worker-expansions=0`。

| 数据集 | 6 线程 `L` / Beam / `--worker-candidates` | 8 线程 `L` / Beam / `--worker-candidates` |
|---|---:|---:|
| GIST1M | 900 / 2 / 225 | 900 / 4 / 170 |
| SIFT1M | 222 / 1 / 0 | 224 / 1 / 0 |

SIFT1M 的 2、4 线程调度实验分别使用 `L / Beam` 为 176 / 4、208 / 2，每线程候选上限为 0。
